# C Preprocessor

## Overview
A C project that implements basic preprocessing operations on C source files.

## Features
- Single-line and multiline comment removal
- Header file inclusion
- Object-like and function-like macro replacement
- Removal of processed #define lines

## Technologies
- C
- GCC
- Linux
- Makefile

## Project Files
- mypreprocessor.c - Main program
- comment.c - Comment handling
- file.c - Header file inclusion
- macro.c - Macro handling
- operation.h - Function declarations
- myheader.h - Project header file
- data.c - Test input
- Makefile - Build instructions

## Compilation
Run `make`.

## Execution
Run `./mypreprocessor data.c`.

## Limitations
This project implements basic preprocessing features and does not reproduce every feature of the standard C preprocessor.
